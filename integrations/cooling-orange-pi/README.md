# Интеграция охлаждения Orange Pi

Кодовые артефакты для PWM-охлаждения Orange Pi Zero W2.

- `pwm_fan_daemon.py` — демон управления вентилятором, MQTT-телеметрия и настройки.
- `dashboard-UI_Lovelace.yaml` — конфигурация панели Home Assistant.

Полная инструкция: [../../docs/cooling-orange-pi.md](../../docs/cooling-orange-pi.md).
