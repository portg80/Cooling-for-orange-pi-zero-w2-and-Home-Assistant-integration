# Интеграция Satisfactory

Эта интеграция демонстрирует цифровой макет умного дома внутри Satisfactory.

- `tonglelamp_v1.lua` опрашивает локальный HTTP endpoint и применяет состояние к игровому источнику света.
- Команда [ToggleLamp.py](../../voice-assistant/commands/ToggleLamp.py) отправляет HTTP-запросы в локальный API управления Satisfactory.

Демо-сценарий фокусируется на освещении: все лампы, группы, отдельные лампы, яркость и цвет.
