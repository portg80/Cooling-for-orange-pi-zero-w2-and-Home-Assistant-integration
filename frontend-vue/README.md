# Vue-интерфейс Afina

Веб-интерфейс Afina построен на Vue 3, TypeScript, Vite, Pinia, Tailwind CSS и Axios.

Интерфейс ожидает backend API ассистента по адресу:

```text
http://127.0.0.1:6789/api
```

API-клиент находится в:

```text
src/modules/voice_assistant/api/apiClient.ts
```

## Установка

```sh
npm install
```

## Запуск для разработки

```sh
npm run dev
```

## Сборка и проверка типов

```sh
npm run build
```

## Линтинг

```sh
npm run lint
```
