# Чеклист содержания главного README

Этот файл фиксирует, какие блоки должны быть отражены в главном README репозитория Afina.

## Первый экран

- Название продукта: Afina.
- Краткое позиционирование: автономный голосовой ассистент для умного дома с локальной обработкой команд.
- Отличие от обычного скрипта: wake word, STT, NLU, TTS, команды, веб-интерфейс, интеграции.
- Таблица демонстраций с видеороликами и статусом сценариев.

## Тест-кейсы и демонстрации

- Активация ассистента ключевым словом «Афина».
- Распознавание голосовой команды.
- Выполнение команды в системе умного дома.
- Озвучивание ответа через TTS.
- Работа веб-интерфейса ассистента.
- Работа Vue-интерфейса, если сценарий уже перенесён.
- Сценарии Home Assistant и Node-RED.
- Отдельная демонстрация системы охлаждения Orange Pi Zero W2.

## Архитектура продукта

- Основной цикл работы ассистента: микрофон, wake word, STT, обработка команды, действие, ответ.
- Роль каждого программного слоя: ядро ассистента, команды, web API, интерфейс, интеграции.
- Внешние технологии: Vosk, PyTorch, Home Assistant, MQTT, Node-RED, Vue, TypeScript, Vite.
- Ссылки на архитектурную документацию и ключевые файлы.

## Голосовой ассистент

- Папка основного проекта: `voice-assistant`.
- Точка запуска: `voice-assistant/main.py`.
- Модуль команд: `voice-assistant/commands`.
- Web API и старый интерфейс: `voice-assistant/core/web_interface`.
- Wake word движок внутри ассистента: `voice-assistant/core/wake_word_ai/WakeWordEngine.py`.
- Текущая модель: `voice-assistant/core/wake_word_ai/TEST/afina_reworked_1.ptc`.

## Wake word модель

- Назначение модели: локальная детекция ключевого слова до запуска полного STT.
- Подготовка JSONL-манифестов через `create_wakeword_jsons.py`.
- Обучение через `train.py`.
- Экспорт оптимизированной модели через `optimize_graph.py`.
- Использование `.ptc` модели через `engine.py` и встроенный `WakeWordEngine.py`.
- Краткое описание признаков MFCC, LSTM-архитектуры, функции потерь и оптимизатора.

## Датасет и подготовка данных

- Модуль записи датасета.
- Скрипты предобработки и приведения аудио к рабочему формату.
- Скрипты нарезки двухсекундных фрагментов.
- Скрипты аугментации позитивных и негативных примеров.
- Скрипты балансировки негативных окон.
- Проверка позитивных примеров через Vosk.
- Сводная статистика датасета: количество примеров, баланс классов, длительность.
- Ссылки на графики и CSV-таблицу в `assets/dataset-stats`.
- Отдельная пометка, что полный аудиодатасет хранится вне репозитория.

## Web-интерфейсы

- Текущий web-интерфейс в составе Python-проекта.
- Отдельный Vue-проект в `frontend-vue`.
- Статус Vue-версии: перенос функционала со старого интерфейса находится в разработке.
- Инструкция по установке npm-зависимостей и запуску Vite.
