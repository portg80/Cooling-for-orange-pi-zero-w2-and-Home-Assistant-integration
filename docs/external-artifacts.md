# Внешние артефакты

Часть файлов намеренно не хранится в Git, чтобы репозиторий оставался практичным, переносимым и пригодным для публикации.

## Не включено

| Артефакт | Причина | Где должен появиться |
| --- | --- | --- |
| Vosk STT модель | Внешняя модель, локально около 87 МБ | `voice-assistant/model_stt/model-small` |
| Большие TTS-веса | Крупные PyTorch-файлы | `voice-assistant/core/TTS/model_tts` |
| Сырой аудиодатасет | Большой размер и возможные личные/сторонние записи | отдельный архив, облако или GitHub Release |
| Аугментированный датасет | Большой объём генерируемых данных | регенерация скриптами или внешнее хранилище |
| Полные train/test манифесты | Содержали абсолютные пути и имена исходных файлов | регенерация через `create_wakeword_jsons.py` |
| Демо-видео | Удобнее хранить как GitHub attachments или Release assets | ссылки в таблице README |
| Python virtualenv | Машинно-зависимое окружение | создать локально |
| `node_modules` | Устанавливаемые зависимости | `npm install` |

## Включено

- TorchScript wake word модели `.ptc`.
- CSV и изображения со статистикой датасета.
- Визуализация MFCC.
- Примерные JSONL-манифесты.
- YAML панели Home Assistant для охлаждения Orange Pi.
