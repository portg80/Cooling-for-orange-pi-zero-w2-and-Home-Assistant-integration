# Локальные зависимости

Afina разделяет исходный код проекта и крупные локальные данные. В репозитории находятся программные модули, документация, примеры манифестов, статистика датасета и компактные модели wake word. Для полного запуска и повторного обучения понадобятся дополнительные файлы.

## Модели

| Компонент | Назначение | Путь |
| --- | --- | --- |
| Vosk STT модель | Офлайн-распознавание речи | `voice-assistant/model_stt/model-small` |
| TTS-веса | Генерация голосовых ответов | `voice-assistant/core/TTS/model_tts` |
| Wake word `.ptc` | Детекция ключевого слова «Афина» | `voice-assistant/core/wake_word_ai/TEST/afina_reworked_1.ptc` |

## Данные для обучения

Для повторного обучения wake word модели нужны позитивные и негативные аудиофрагменты. Скрипт `create_wakeword_jsons.py` создаёт `train.json` и `test.json` для выбранных локальных директорий.

В репозитории уже есть:

- скрипты записи, нарезки, аугментации и анализа датасета;
- CSV и графики со статистикой набора данных;
- пример MFCC-визуализации;
- примеры JSONL-манифестов.

## Окружение

Python-зависимости устанавливаются в локальное virtualenv-окружение. Vue-интерфейс устанавливает frontend-зависимости через `npm install`.
