# Dataset Tools

В этой папке лежат скрипты записи, предобработки, аугментации, нарезки и анализа аудио для wake word модели Afina.

Скрипты работают с локальными директориями аудиодатасета. Перед запуском укажите пути к своим позитивным, негативным и выходным папкам.

Обзор пайплайна находится в [docs/dataset-pipeline.md](../docs/dataset-pipeline.md).
