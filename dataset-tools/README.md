# Dataset Tools

В этой папке лежат скрипты записи, предобработки, аугментации, нарезки и анализа аудио для wake word модели Afina.

Скрипты скопированы без сырого аудио и без Python virtualenv. Некоторые файлы сохраняют локальные пути из рабочего окружения как значения по умолчанию; перед повторным запуском их нужно заменить на свои директории датасета.

Обзор пайплайна находится в [docs/dataset-pipeline.md](../docs/dataset-pipeline.md).
