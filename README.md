# Afina. Описание проекта.

Afina — автономный голосовой ассистент для локального управления умным домом, компьютером, телефоном и внешними интеграциями. 

<img width="1672" height="941" alt="Постер афина (1)" src="https://github.com/user-attachments/assets/b90ce14f-e744-43ef-b1e9-d7c5fd4a7b96" />


В фильме "Железный человек" у Тони Старка был голосовой ассистент Джарвис. Большинство реальных проектов, которые пытались реализовать похожий функционал, заканчивались обычно на открытии приложения по команде. 

Мой проект "Afina" нацелен же на возможность интеграции с большинством окружающих нас устройств и систем (IoT-устройства, телефоны, веб-сервисы, компьютеры, различные API). А так же в дальнейшем будут улучшены алгоритмы сопоставления команд для того чтобы ассистент понимал более свободные формулировки команд с помощью NLU библиотек.

- Аппаратной основой является одноплатный компьютер [Orange Pi Zero 2W](http://www.orangepi.org/html/hardWare/computerAndMicrocontrollers/details/Orange-Pi-Zero-2W.html) и собранный для него модуль управления активным охлаждением.

- Для интеграции различных умных устройств используеться система [Home Assistant](https://www.home-assistant.io/integrations) - одно решение для умных устройств и одно приложение для пользователя.

- Для дружелюбного (к пользователю) создания различных сценариев используеться система визуального программирования [Node-RED](https://nodered.org/), но при остается возможность внедрять JavaScript или Python скрипты.

- Для голосового управления системой и расширения интеграционных функций был разработан голосовой помощник Afina, который работает как умная колонка и запускает сценарии Node-RED или кастомные навыки написанные пользователем или любым другим разработчиком на python. Это позволяет внедрить в систему не только умный дом, но и компьютер, телефоны, телевизоры, другие умные колонки или отдельные системы.

Гибкость дает вам возможнось создать практически любой сценарий который придет к вам в голову, или скачать уже готовый навык, который написал другой человек и использовать его в своей системе.

## Примеры

Стандартные для дома автоматизации:
- включение света или различных устройств (даже не умных), например кондиционеров, телевизоров и тд.
- потоп в ванной - перекрываем краны и сообщаем об этом в уведомлении, в месседжере и тд. 
- изменение и отслеживание параметров устройств, например подключив к котлу отопления блок "WIFI реле" или термостат вы сможете управлять им удаленно.

**Но суть проекта в том, чтобы вы могли реализовать более сложные сценарии, насколько хватит вашей фантазии...**

---
### Нужный вам автобус проезжает мимо остановки в разное время, а вам до этой остановки еще нужно успеть вовремя дойти?
Этот кейс я уже реализовал как пример:
- сценарий будет остлеживать в реальном времени местоположение автобуса с сайта [busti.me](https://ru.busti.me/)
- по его местоположению выводится информация во сколько будет автобус на остановке
- от вашего местоположения (по GPS смартфона) через бесплатный веб сервис расчитываеться время пути до остановки. Каждую минуту данные пересчитываются.
- по полученным данным сценарий расчитывает:
  -  во сколько вам выйти из дома чтобы успеть на автобус
  -  на сколько вы опаздываете
  -  во сколько на вашем телефоне установить будильник, и устанавливает его сам через Android-Itent

Все это отображается на отдельной странице и может быть озвучено голосовым ассистентом.

---

### Ставите воду на плиту для пельменей и забываете о ней? 
Все готово для того чтобы:
- подключить несколько датчиков тепературы и движения
- собрать сценарий отслеживания что плита включена и что вас нет на кухне

Теперь колонка может:
- звать вас на кухню например каждые 5 минут отсутствия
- через 3 минуты колонка скажет: “Помешайте, чтобы не прилипли”
- скажите ей что пельмени всплыли, она засекёт еще 5 минут до готовности

---
### Хотите чтобы ваша умная колонка могла засечь время на готовку конкретной лапши, конкретной толщины? 
- Вы можете создать сценарий чтобы по названию лапши система брала нужное для конкретной лапши время, и ставила таймер прямо на вашем телефоне.
- Захотите добавить в эту последовательность камеру, и вот система способна распознавать штрихкоды с упаковки чтобы не называть конкретные названия голосом.
- Можете прикрутить расчет БЖУ и следить за питанием.

---
### У вас есть сиcтема видеонаблюдения дома, например Hikvision?
Сделайте сценарий при котором сказав команду голосовому ассистенту "Выведи камеры на экран":
- включится по wi-fi телевизор (если телевизор уже включен то система это поймет)
- на экране телевизора запустится браузер с адресом страницы, на которой будет отображаться картинка с камер

Телевизор управляется по wi-fi через оффициальное API, что позволяет выполнять такие сложные действия как открытие конкретных приложений и их экранов.

# Техническое описание репозитория
## Что реализовано

- Детекция ключевого слова «Афина» локальной PyTorch/TorchScript-моделью.
- Офлайн-распознавание речи через Vosk/Kaldi.
- Модульная система команд на Python.
- Сопоставление команд по точному совпадению, ключевым словам, вхождению и нечёткому совпадению.
- Flask REST API для управления действиями ассистента.
- Веб интерфейс на Vue 3, TypeScript, Vite, Pinia, Tailwind CSS и Axios.
- Интеграции с Home Assistant через MQTT протокол.
- Создание сценариев автоматизации умного дома через визуальное программирование в Node-RED.
- Отдельная система управления активным охлаждением Orange Pi Zero W2 с PWM-управлением оборотов и веб интерфейсом Home Assistant.
- Скрипты многопоточной синхронной записи ключевого слова, а также предобработки, аугментации, нарезки и анализа датасета для обучения wake word модели.

## Структура репозитория

```text

wakeword-training/               пайплайн обучения и оптимизации wake word модели

integrations/cooling-orange-pi/  PWM-демон охлаждения и Lovelace YAML

assets/dataset-stats/            графики и CSV-статистика датасета
assets/wakeword/                 визуализации MFCC
docs/                            документация проекта
```

## Основной ассистент

Точка входа находится в [voice-assistant/main.py](voice-assistant/main.py). При запуске инициализируются wake word движок, Vosk-распознаватель, менеджер команд, NLU-слой, звуковой модуль и веб-интерфейс.

Ключевые файлы:

- [WakeWordEngine.py](voice-assistant/core/wake_word_ai/WakeWordEngine.py) — инференс wake word модели по аудиопотоку.
- [Recognizer.py](voice-assistant/core/Recognizer.py) — локальное распознавание речи через Vosk.
- [Command_manager.py](voice-assistant/core/Command_manager.py) — динамическая загрузка команд.
- [Base_command.py](voice-assistant/commands/Base_command.py) — базовый API команд.
- [api.py](voice-assistant/core/web_interface/api.py) — REST API управления ассистентом.
- [server.py](voice-assistant/core/web_interface/server.py) — Flask-сервер на порту `6789`.

Подробнее: [docs/architecture.md](docs/architecture.md).

## Wake Word

Подсистема wake word обучалась как бинарный классификатор 2-секундных аудиофрагментов. Модель использует 40 MFCC-признаков, LSTM-слой и экспортируется в TorchScript `.ptc` для быстрого локального инференса.

Фактическая последовательность:

1. Подготовка позитивных и негативных фрагментов скриптами из [dataset-tools/scripts](dataset-tools/scripts).
2. Создание JSONL-манифестов через [create_wakeword_jsons.py](wakeword-training/VoiceAssistant/wakeword/scripts/create_wakeword_jsons.py).
3. Обучение через [train.py](wakeword-training/VoiceAssistant/wakeword/neuralnet/train.py).
4. Оптимизация модели через [optimize_graph.py](wakeword-training/VoiceAssistant/wakeword/neuralnet/optimize_graph.py).
5. Использование `.ptc` модели через [engine.py](wakeword-training/VoiceAssistant/wakeword/engine.py) или встроенный движок ассистента.

Модель, используемая ассистентом: [wakeword21.ptc](voice-assistant/core/wake_word_ai/WW_models/wakeword21.ptc).

Подробнее: [docs/wakeword-training.md](docs/wakeword-training.md).

## Датасет

Раздел с датасетом содержит скрипты записи, предобработки, аугментации, нарезки и анализа аудио. Полный аудиодатасет хранится отдельно из-за объёма и состава исходных записей.

Подробнее: [docs/dataset-pipeline.md](docs/dataset-pipeline.md).

## Команды и интеграции

В проекте есть базовые команды и демонстрационные навыки:

- приветствие;
- дата и время;
- статус прослушивания;
- mute/unmute микрофона;
- установка будильника на телефоне Android-Itent'ом через MQTT [SetAlarmCommand.py](../voice-assistant/commands/SetAlarmCommand.py);
- поиск телефона с помощью установки таймера Android-Itent'ом через MQTT [find_my_phone.py](../voice-assistant/commands/find_my_phone.py).;
- переключение аудиомаршрута на ПК в микшере Voicemeter через их API;
- управление светом Satisfactory по всем лампам, группе, конкретной лампе, яркости и цвету;
- демонстрационная логика Satisfactory для чтения состояния цистерн, хранилищ и производственных секций;
- пример произвольного навыка с расчётом стоимости пиццы.

Демонстрационные сценарии описаны в [docs/demo-scenarios.md](docs/demo-scenarios.md).

## Веб-интерфейсы

В проекте есть два направления интерфейса:

- `voice-assistant/core/web_interface` — Flask-интерфейс, который запускается вместе с ассистентом на `http://127.0.0.1:6789`.
- `frontend-vue` — интерфейс на Vue 3 и TypeScript, который обращается к Flask API по адресу `http://127.0.0.1:6789/api`.

## Быстрый запуск

Минимально:

```sh
cd voice-assistant
python main.py
```

Перед запуском нужно установить Python-зависимости, добавить Vosk-модель в `voice-assistant/model_stt/model-small`, проверить индекс микрофона в `main.py` и убедиться, что путь к `.ptc` модели wake word существует.

Подробно: [docs/quick-start.md](docs/quick-start.md).
